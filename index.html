Política de Privacidad

Task Calendar

Última actualización: 3 de octubre de 2026

1. Introducción

Task Calendar es una aplicación móvil de gestión de tareas académicas desarrollada por Carolina Karina Kantuta Cruz como proyecto de grado del Instituto Tecnológico Don Bosco. Esta política describe cómo se recopilan, usan y protegen los datos del usuario.

2. Datos que recopilamos

  • Correo electrónico (para autenticación)
  • Nombre del usuario (para personalización)
  • Foto de perfil (opcional)
  • Materias, tareas y datos de uso (para el funcionamiento de la app)

3. Cómo usamos los datos

  • Autenticación y acceso seguro
  • Personalización de la experiencia
  • Cálculo de rachas y estadísticas
  • Envío de notificaciones locales

4. Almacenamiento y seguridad

Los datos se almacenan en Supabase (PostgreSQL) con:

  • Encriptación de contraseñas (bcrypt)
  • Row Level Security (RLS) para aislamiento por usuario
  • Conexiones HTTPS

5. Compartición de datos

NO compartimos datos con terceros. No hay publicidad ni análisis de terceros.

6. Derechos del usuario

El usuario puede acceder, modificar o eliminar sus datos contactando al correo indicado abajo.

7. Menores de edad

La app está destinada a estudiantes. No recopilamos datos de menores sin consentimiento parental.

8. Cambios en la política

Notificaremos cambios importantes a través de la app.
